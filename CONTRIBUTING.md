# 🤝 Contributing

Thanks for your interest in contributing! 🚀

This repository aims to be a **high-signal, curated guide** to quant interview preparation.

We welcome contributions — but we prioritize **quality over quantity**.

---

## ✅ What You Can Contribute

You can help by:

- Adding **high-quality resources**
- Improving explanations or structure
- Fixing errors or outdated links
- Adding missing sections (e.g., new prep strategies, guides)

---

## 📌 Contribution Guidelines

Please follow these rules:

- Keep contributions **practical and useful**
- Add a **short description** for each resource
- Avoid duplicates
- Avoid low-quality or spammy links
- Keep formatting consistent

Think: *"Would this actually help someone prepare better?"*

---

## 🔧 How to Contribute (Step-by-Step)

### 1. Fork the repository

Click the **"Fork"** button (top right of the repo page)

This creates your own copy of the repo.

---

### 2. Make your changes

- Edit the README or other files
- Add your improvements

---

### 3. Commit your changes

Click:
- "Commit changes"

Write a clear message, for example:
- `Add new mental math resource`
- `Improve probability section`

---

### 4. Open a Pull Request (PR)

- Go back to the original repo
- Click **"Pull requests"**
- Click **"New pull request"**
- Select your fork
- Submit your changes

---

## 👀 What Happens Next?

We will review your contribution and:
- approve it ✅
- request changes ✏️
- or decline it ❌ (if it doesn't fit the repo's standards)

---

## ⭐ Tip

If you're unsure whether something is worth adding, feel free to:
- open an issue
- or suggest it in a PR

---

Thanks for helping make this resource better for everyone 🙌
